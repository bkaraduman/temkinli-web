# temkinli-web

Temkinli uygulamasının web sitesi (temkinli.app), GitHub Pages ile yayınlanır.

- `index.html` – tanıtım sayfası (geçici; Claude Design tasarımıyla değiştirilecek)
- `gizlilik/`, `kosullar/` – uygulama deposundaki `content/legal/*.html` dosyalarının kopyası
- `destek/` – destek sayfası (App Store destek adresi)
